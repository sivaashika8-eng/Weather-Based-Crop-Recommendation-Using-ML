# Weather Based Crop Recommendation Using ML 🌱

## Project Description

Weather Based Crop Recommendation Using Machine Learning is a project that recommends a suitable crop based on soil and weather conditions. The system uses machine learning to analyze the given environmental parameters and predict a suitable crop.

## Input Parameters

The model uses the following parameters:

* N (Nitrogen)
* P (Phosphorus)
* K (Potassium)
* Temperature
* Humidity
* pH
* Rainfall

## Output

The system predicts the suitable crop based on the given input parameters.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab
* Machine Learning

## Dataset

The dataset contains the following columns:

N, P, K, temperature, humidity, ph, rainfall, label

The first seven columns are used as input features, and `label` is the crop to be predicted.

## Project Workflow

1. Load the dataset.
2. Analyze the data.
3. Preprocess the data.
4. Train the machine learning model.
5. Evaluate the model.
6. Provide input values.
7. Predict the suitable crop.
